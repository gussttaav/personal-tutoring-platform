# Phase 2 — Launch

Two tasks, at two different moments. The first ships **with Block 1's publication**: the day
`llm-agents` has a public lesson, the first course's closing bridge and landing page point at it.
The second ships **when the course is complete**: the «new course» announcement over the opt-in
`COURSE-P6-02` built, with its dry run and its idempotent key.

Nothing else. Sitemap, hreflang, JSON-LD, the catalog card, search and progress all pick the
course up from its first published lesson without a task.
