otra lista, la de lo que el agente no promete: que la tarea se haga y que el texto final diga la
verdad sobre el entorno.

## El adaptador y lo que promete

El **adaptador** es la pieza que implementa la firma de `modelo` hablando con un servidor:

```text
ModeloAPI(nombre="local", max_tokens=1024)
modelo(mensajes, herramientas) -> respuesta
```

`nombre` es el modelo que el servidor tiene cargado y `max_tokens` la reserva de cada respuesta. Una
instancia es una función con la firma de siempre, y su contrato tiene cinco cláusulas:

1. **Traduce M sin tocar el contenido.** El contenido de los mensajes `sistema` va al campo
   `system`, unido y en su orden. Cada uno de los demás pasa a `messages`, en el mismo orden, con
   el rol en inglés (`user`, `assistant`) y su contenido tal cual, cadena o lista de bloques. Las
   herramientas van a `tools` sin cambios. Es la tabla de la lección anterior, y nada más.
2. **Devuelve la respuesta tal como llega**: el campo `content`, una lista de bloques que el bucle
   añade a M sin copiarla ni reescribirla. Los ids de las llamadas los pone el servidor, y el
   `tool_result` de cada una copia el suyo.
3. **Nunca devuelve una respuesta cortada.** Si `stop_reason` es `max_tokens`, lanza una
   excepción. Es lo que prometió <Leccion slug="el-bucle">la lección del bucle</Leccion>: el bucle
   decide por los bloques, y una respuesta cortada puede no traer ningún `tool_use` sin estar
   terminada, o traer uno con los argumentos a medias. Fuera de ese caso, `stop_reason` no se mira.
4. **Un error del servidor es una excepción con su motivo.** Una petición que no cabe en la
   ventana de contexto (un 400), un modelo que el servidor no tiene (un 404) o un servidor apagado
   salen de `modelo`, y por tanto del bucle, que sólo deja salir eso. El texto que da el servidor
   va en la excepción, para que sepas qué ha pasado.
5. **No recuerda nada entre llamadas.** Guarda el `usage` de la última petición para quien quiera
   mirarlo, y la siguiente no lo lleva. Como el servidor, cada vez recibe M entero.

La quinta es la que hace que el cambio sea un cambio de pieza y no una reescritura. El modelo
guionizado tampoco recordaba nada que no estuviera en M, aparte de su puntero, así que el bucle no
puede notar la diferencia. `bucle.py`, `permisos.py`, `agente.py` y `entorno.py` no cambian un
byte, y el agente sobre el modelo local es `agente(ModeloAPI(), pedido, entorno)`.

### Lo que el guion nunca hacía

Que el bucle no cambie no quiere decir que no tenga trabajo nuevo. Un modelo de verdad devuelve
cosas que ningún guion del bloque anterior devolvía, y cada una cae en una garantía distinta, o en
ninguna:

| Lo que devuelve el modelo | Quién lo recoge |
|---|---|
| texto y llamadas en la misma respuesta | el bucle: hay llamadas, así que sigue; el texto se queda en M |
| una llamada a una herramienta que no existe, o con un argumento de más | `ejecutar`: no cumple el esquema, vuelve como error y el modelo lo ve |
| una respuesta cortada por la reserva | el adaptador: lanza una excepción |
| una respuesta sin llamadas, en inglés, que no ha mirado el entorno | nadie: es una respuesta sin llamadas, y el bucle devuelve `fin` |
| un texto final que no cuenta lo que ha pasado | nadie: es lo que el agente no promete |

Las tres primeras filas son el contrato trabajando. Las dos últimas son trabajo para el resto del
bloque, que va añadiendo capas al harness para que pasen menos.

Y hay una diferencia que no está en ninguna fila: el modelo local **sortea** cada token, así que el
mismo pedido puede dar dos ejecuciones distintas. Por eso los tests del agente se quedan sobre el
guion. Un test fija el modelo para que, si no pasa, la culpa sólo pueda ser del harness; lo que
hace el modelo con el harness no se prueba, se mide, y eso lo hace un banco de pruebas, más adelante
en el bloque.

```python
"""modelo(mensajes, herramientas) -> respuesta, sobre la API de mensajes. Lección 33 del curso.

El adaptador: traduce M al protocolo, manda la petición con urllib y devuelve la respuesta
tal como llega. Ninguna biblioteca del proveedor.
"""
import json
import os
import urllib.error
import urllib.request

URL = os.environ.get("ANTHROPIC_BASE_URL", "http://localhost:11434") + "/v1/messages"
CLAVE = os.environ.get("ANTHROPIC_API_KEY")       # el servidor local no la pide
ROLES = {"usuario": "user", "asistente": "assistant"}


def peticion(nombre, max_tokens, mensajes, herramientas):
    """M en el protocolo: el prompt de sistema, a su campo; los demás, con el rol en inglés."""
    p = {"model": nombre, "max_tokens": max_tokens, "thinking": {"type": "disabled"},
         "system": "\n\n".join(c for rol, c in mensajes if rol == "sistema"),
         "messages": [{"role": ROLES[rol], "content": c} for rol, c in mensajes if rol != "sistema"]}
    if herramientas:
        p["tools"] = list(herramientas)
    return p


def enviar(p):
    """Un POST con la petición; lo que contesta el servidor, leído del JSON."""
    cabeceras = {"content-type": "application/json"}
    if CLAVE:
        cabeceras.update({"x-api-key": CLAVE, "anthropic-version": "2023-06-01"})
    req = urllib.request.Request(URL, data=json.dumps(p).encode("utf-8"), headers=cabeceras)
    try:
        with urllib.request.urlopen(req, timeout=300) as r:
            return json.load(r)
    except urllib.error.HTTPError as e:              # un 400, un 404: el servidor dice por qué
        raise RuntimeError("el servidor contesta %d: %s" % (e.code, e.read().decode("utf-8")))
```

La mitad de abajo es la clase. Tiene la forma de `ModeloGuionizado`, un objeto que se llama como
una función, y lo único que hace además de traducir y enviar es la tercera cláusula:

```python
class ModeloAPI:
    """modelo(mensajes, herramientas) -> respuesta, de un modelo que sirve otro programa."""
    def __init__(self, nombre="local", max_tokens=1024):
        self.nombre, self.max_tokens = nombre, max_tokens
        self.usage = None                             # el de la última petición, para quien mire

    def __call__(self, mensajes, herramientas=()):
        r = enviar(peticion(self.nombre, self.max_tokens, mensajes, herramientas))
        self.usage = r["usage"]
        if r["stop_reason"] == "max_tokens":          # una respuesta cortada no se devuelve
            raise RuntimeError("la respuesta no cabe en max_tokens=%d" % self.max_tokens)
        return r["content"]
```

Dos cláusulas del contrato se pueden comprobar sin servidor, y van a `tests/test_api.py`: la

```python
"""El adaptador, sin servidor: la traducción de M y la respuesta cortada. Lección 33 del curso."""
import unittest
from unittest import mock

import api
from agente import SISTEMA, inicio
from entorno import HERRAMIENTAS, llamada, resultado


class TestAdaptador(unittest.TestCase):
    def test_la_traduccion(self):
        r = [llamada("t1", "leer", ruta="lista.txt")]
        M = inicio("¿Qué hay en lista.txt?") + [("asistente", r), ("usuario", [resultado("t1", "pan")])]
        p = api.peticion("local", 1024, M, HERRAMIENTAS)
        self.assertEqual(p["system"], SISTEMA)
        self.assertEqual([m["role"] for m in p["messages"]], ["user", "assistant", "user"])
        self.assertEqual([m["content"] for m in p["messages"]], [c for _, c in M[1:]])
        self.assertEqual(p["tools"], HERRAMIENTAS)

    def test_la_respuesta_cortada(self):
        cortada = {"content": [{"type": "text", "text": "pan, le"}], "stop_reason": "max_tokens",
                   "usage": {"input_tokens": 453, "output_tokens": 1024}}
        with mock.patch("api.enviar", return_value=cortada):
            with self.assertRaises(RuntimeError):
                api.ModeloAPI()(inicio("¿Qué hay en lista.txt?"), HERRAMIENTAS)


if __name__ == "__main__":
    unittest.main()
```

Falta un programa que reciba un pedido y enseñe qué pasa en cada turno. `correr.py` lo hace sin
tocar el bucle, con un modelo que envuelve a otro: `Traza` le pasa cada M al modelo de verdad y
escribe lo que viaja. Las observaciones del turno anterior las encuentra en el último mensaje de M,
que es justo donde el bucle las deja.

```python
"""Un pedido al agente, contra el modelo local, turno a turno. Lección 33 del curso.

    python correr.py "¿Qué recetas hay y cuál lleva cebolla?"
"""
import json
import sys
import time

from agente import agente
from api import ModeloAPI
from entorno import ENTORNO


def linea(b):
    """Un bloque en una línea, y si es una observación, si es un error."""
    if b["type"] == "text":
        return "texto        " + " ".join(b["text"].split())
    if b["type"] == "tool_use":
        return "llamada      %s %s" % (b["name"], json.dumps(b["input"], ensure_ascii=False))
    return ("error        " if b["is_error"] else "observación  ") + b["content"].replace("\n", " / ")


class Traza:
    """Un modelo que envuelve a otro y escribe lo que viaja. Para el bucle, es un modelo más."""
    def __init__(self, modelo):
        self.modelo, self.turno = modelo, 0

    def __call__(self, mensajes, herramientas=()):
        rol, contenido = mensajes[-1]
        if rol == "usuario" and isinstance(contenido, list):     # las observaciones de antes
            for b in contenido:
                print("  →  " + linea(b))
        self.turno, t = self.turno + 1, time.time()
        r = self.modelo(mensajes, herramientas)
        u = self.modelo.usage
        print("turno %d  %.0f s  %d tokens de entrada" % (self.turno, time.time() - t,
              u["input_tokens"] + u.get("cache_read_input_tokens", 0)))
        for b in r:
            print("  ←  " + linea(b))
        return r
```

Al final del fichero, el agente con el modelo envuelto. El entorno es todavía el diccionario en
memoria, una copia por ejecución, y no hay usuario: una escritura se deniega, como en la traza de
arriba. Preguntarte de verdad llega con los permisos, más adelante en el bloque.



Los segundos dependen de tu máquina, y la primera ejecución tarda más porque el servidor carga los
pesos. El texto puede salir con otras palabras. Lo que tiene que coincidir es la forma: dos
llamadas en la primera respuesta, contestadas en el orden en que se pidieron, y una respuesta sin
llamadas en el segundo turno. Fíjate en los tokens: 460 para una pregunta de siete palabras, porque
la mayor parte son el prompt de sistema y las cuatro herramientas, que viajan en cada turno.

El agente ya corre contra un modelo de verdad, y el bucle que lo mueve es el del bloque anterior,
sin una línea cambiada. Pero lo que mueve sigue siendo un juguete: un diccionario de cuatro
ficheros en memoria y cuatro herramientas pensadas para él. `buscar` compara tal cual, y bastó una
mayúscula para que el modelo dejara de leer y se pusiera a adivinar.

Un agente de programación trabaja sobre un repositorio en tu disco, y lo que necesita es leerlo,
buscar en él, cambiar un fichero sin reescribirlo entero y ejecutar los tests. La lección
siguiente, sobre las herramientas de ficheros, cambia el diccionario por los ficheros de verdad y
le da al agente esas herramientas, cada una con un contrato que deja comprobar lo que ha hecho un
modelo pequeño.
